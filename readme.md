<summary>Общий вид проекта</summary>

*требуется обновление*
```
/*Корень проекта*
  ├── build/.................. # Директория сборки проекта
  │
  ├── core/................... # Ядро приложения (содержит ВСЕ
  │   │                          функциональные модули для приложения)
  │   │
  │   ├── logger/............. # Директория с реализацией класса Logger
  │   │
  │   ├── CoreManager.h ...... # Менеджер запуска основной
  │   └── CoreManager.cpp        функциональности
  │
  ├── network/................ # Сетевой модуль
  │   │
  │   ├── handlers/........... # Обработчики протоколов
  │   │   │
  │   │   ├── TcpHandler.h
  │   │   ├── TcpHandler.cpp
  │   │   ├── UdpHandler.h
  │   │   ├── UdpHandler.cpp
  │   │   ├── MacHandler.h
  │   │   └── MacHandler.cpp
  │   │
  │   ├── messages/........... # Протокольные структуры
  │   │   ├── Message.h
  │   │   └── TcpMessage.h
  │   │
  │   └── NetworkManager.h ... # Менеджер подключений
  │
  ├── utils/.................. # Вспомогательные утилиты
  │   │
  │   ├── time_provider/...... # Утилита ведения собственного времени
  │   │
  │   ├── env_loader/......... # Утилита получения значений конфигурации
  │   │
  │   └── AppConfig.h ....... # Определения констант, макросы и дефайны
  │
  └── main.cpp ............... # Главная точка запуска
```

<spoiler>
<summary>Подключение к удалённому стенду (durabook, astra)</summary>

1) Убедиться, что ваша сеть поддерживает ipv6, ссылки для проверки: [1](https://test-ipv6.com), [2](https://ipv6-test.com)
2) Сгенерировать rsa ssh ключ (если ключей в .ssh нету)
   `ssh-keygen -t ed25519 -C "your_email@example.com"`, 
   следовать инструкции (указать имя файла-ключа, задать пароль, ексли есть желание (доп. мера защиты)). В домашней директории найти каталог .ssh, передать .pub на nikitoniy2468@gmail.com
3) после выполнения шагов 1,2, подключиться, `ssh -Xv6 user@nikitonz-astra.ddns.net`
</spoiler>
