# Проект вычислительного устройства (ВУ)

Ориентирован на платформу Astra 1.7

_Для ознакомления с инструментарием git-а перейти [сюда](./docs/git_guide.md)_

> Для понимания и ориентации в проекте ознакомьтесь со **структурой** проекта

```
/*Корень проекта*
  ├── core/              		# Ядро приложения
  │   ├── CoreManager.h
  │   └── CoreManager.cpp
  ├── network/           		# Сетевой модуль
  │   ├── handlers/      		# Обработчики протоколов
  │   │   ├── TcpHandler.h
  │   │   ├── UdpHandler.h
  │   │   └── EthHandler.h
  │   ├── NetworkManager.h
  │   └── messages/      		# Протокольные структуры
  │       ├── Message.h
  │       ├── TcpMessage.h
  │       └── ...
  ├── utils/             		# Вспомогательные утилиты
  │   ├── TimeProvider.h
  │   └── ...
  └── main.cpp
```
